# 🚀 Java Mini Projects Collection

A collection of beginner-to-intermediate Java projects developed using Core Java concepts. These projects demonstrate Object-Oriented Programming (OOP), user interaction, control flow, exception handling, and basic application development.

## 📌 Project Overview

This repository contains multiple Java mini projects designed to strengthen programming fundamentals and practical problem-solving skills.

These projects are suitable for:

- B.Tech / Engineering Students
- Java Beginners
- Academic Mini Projects
- Placement Preparation
- OOP Concept Practice
